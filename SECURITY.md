# Security

LabelSeek runs on the pages you inspect and asks for access to all sites, so security reports matter.

## Reporting a problem

- For anything sensitive, such as a way a web page could make LabelSeek run code or leak data, email darestaton.dev@gmail.com with the steps to reproduce. Please don't open a public issue until it's fixed.
- For anything else, open an issue at https://github.com/darestaton/labelseek/issues.

## What LabelSeek does and doesn't do

- It makes no network requests and stores nothing. Everything is processed on your device.
- It only runs on a tab after you open the side panel on it, and it stops when you pause or close the panel.
- It never changes a page's content, fills forms or clicks anything on its own.
- It ships all of its code in the extension package and loads no remote code.

## Supported versions

Only the latest version on the Chrome Web Store is supported.
